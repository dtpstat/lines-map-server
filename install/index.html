Подключение к PostgreSQL

Шаг 3 из 7

База, schema и роли приложения

Мастер создаст недостающие роли и БД, установит PostGIS, применит migrations и проверит runtime privileges.

Шаг 4 из 7

Первый администратор

Создаётся защищённый bootstrap-superuser со всеми правами. Online Basic-auth не используется.

Шаг 5 из 7

Шаг 6 из 7

Логи и security deployment

Параметры файловых журналов и стабильный ключ шифрования MFA. Если ключ оставить пустым, мастер сгенерирует 32-byte base64url secret.

Шаг 7 из 7

Финальная проверка

Мастер проверит полный runtime config, сделает backup существующего .env, атомарно запишет настройки и уничтожит одноразовое состояние установки.

PostgreSQL superuser password и пароль первого администратора в .env не сохраняются.
